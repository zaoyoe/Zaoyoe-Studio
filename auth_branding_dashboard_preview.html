3

你在 Supabase 里照这个填

填完后跑 readiness 就能验收

  1. 把上面的 4 个 Redirect URL 全部加到 Authentication URL Configuration。
  2. 把 4 个模板文件复制到对应 Email Template。
  3. 每个邮件按钮链接都保留 {{ .ConfirmationURL }}。
  4. Custom SMTP 暂时可以不开，不影响登录和找回密码。
  5. Custom Domain 也是可选，等 DNS/SSL 都准备好再做。
