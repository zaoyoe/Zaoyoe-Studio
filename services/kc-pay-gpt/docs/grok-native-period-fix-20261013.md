# Grok 新版计费周期与年付摘要修正（2026-10-13）

## 故障证据

用户任务 `qgda77qf` 使用 `grok_bundle_premium_annual`，13:46:40 已通过官方账号登录核验，13:46:52 在周期定位阶段报 `GROK_ENTRY_MISSING`。失败截图显示套餐页面已经加载，页面为英文，右上角包含 Monthly / Annual。任务尚未选择套餐或提交付款，原日志记录卡密已回滚为未使用。

根因是此前定位器遗漏官方英文 radiogroup 名称 `Billing interval`，只支持 `Billing period` / `Billing cycle`。只读实查进一步确认中文版年付 radio 的可见名称为“年度”，同样未被原正则覆盖。官方公开脚本也使用 `Billing interval`；实际 radio 节点为 SPAN，配有镜像 input。

切换年度后，官方套餐 CTA 是“订阅 Premium 每年, 最受欢迎”。只读打开结账后，摘要实际为“年度订阅 / US$300.00”，不使用原测试夹具假设的“计划价格 / US$300.00/年”。此前模拟测试通过不代表覆盖了这些实际组件文案，已按实查结构修正。

## 修改

- `grok-native-checkout.js` 支持 `Billing interval` 与“年度”；仍限定已知官方周期组和唯一可见目标，不点击泛化文本或未知 radio。
- 选择后只确认本次定位的目标 radio 已选中，不能被其他无关选中控件误判成功。已有目标选中时不重复点击，避免官方控件再次切换。
- 订单汇总识别“年度订阅 / Yearly subscription”及“月度订阅 / Monthly subscription”的明确周期标签，同时保留带周期单位的“计划价格 / Plan price”。周期标签与金额后缀矛盾、无明确周期、重复价格行仍被拦截。
- 年付核验完整年度标准价和本次官方购物车；不能用折算月价 USD25 替代 Premium 年费 USD300。首期、续费、税费和支付结果的现有校验保持生效。
