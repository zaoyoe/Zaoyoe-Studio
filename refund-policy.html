1. 政策概述

积分及多数数字商品具有即时入账、即时使用、可复制或不可逆交付的特点。除本政策列明的情形、商品页面另有承诺或法律法规另有强制规定外，充值成功、权益到账或数字内容已交付后一般不支持无理由退款。

重要说明：AI 输出具有随机性。仅因结果风格、构图、文字、人物细节或主观质量未达到预期，通常不构成现金退款或积分返还理由。平台确认的异常扣费和符合条件的失败任务将按下述规则处理。

2. AI 工作台积分返还

  • 明确拒绝或未执行：在积分模式下，如请求被平台或上游明确拒绝、任务未实际执行，且系统确认对应费用可以释放，已预扣积分将自动退回或不计入最终扣减。
  • 平台故障导致无结果：如任务因可核验的平台错误失败且未产生可用结果，我们会根据任务记录、上游结算状态和实际成本退回全部或相应积分。
  • 部分结果：请求多张图片或多个结果但仅部分成功时，将结合实际交付数量、定价规则和上游成本处理，可能按实际结果计费，而非当然全额返还。
  • 状态不明：如网络中断、上游超时或任务状态暂时无法确认，平台会先保留任务与扣费记录，待核实是否已产生上游成本或结果后再决定是否返还。
  • 自有 API Key 模式：此模式通常不扣除本站生成积分。第三方已收取的 API 费用、额度或套餐权益由对应提供商的规则决定，本站无法代其退款。

自动返还通常会直接反映在账户余额或任务记录中。如任务结束后余额长期未更新，请勿重复提交相同任务，先保留任务编号并联系我们核查。

3. 可申请退款或更正的情形

  • 同一笔订单因支付或系统错误发生可核验的重复扣款；
  • 付款成功但积分或商品在合理时间内始终未到账，且平台无法补发；
  • 平台标价、结算或订单系统错误导致实际扣款与确认页面明显不一致；
  • 因平台原因永久无法提供已购买且尚未消费的对应服务；
  • 商品页面明确承诺可退款，且申请满足其公示条件；
  • 适用法律法规要求退款或赋予您不可放弃的消费者权利。

4. 通常不予退款的情形

  • 积分、权益、卡密、账号、文件、提示词包或其他数字内容已经使用、查看、复制、下载、兑换或交付；
  • AI 任务已正常执行并产生结果，仅因主观不满意、输入错误、未阅读模型说明或预期差异申请退款；
  • 因用户设备、浏览器、网络、地区限制、自有 API Key、上游账户余额或第三方账户状态导致无法使用；
  • 购买前未核对商品说明、适用条件、兼容性、交付方式或计费规则；
  • 赠送积分、活动奖励、优惠券、签到权益或其他未实际支付对价的权益；
  • 因违法违规、欺诈、滥用、攻击、侵权或违反服务条款而被限制服务；
  • 无法提供订单、支付或任务信息，且平台也无法通过账户和系统记录核验交易。

5. 申请方式

请使用购买账户关联邮箱（如可用）发送申请至 zaoyoe@gmail.com，主题注明“退款/异常扣费申请”，并提供：

  • 账户邮箱或用户 ID；
  • 订单号、交易号、支付时间和实际支付金额；
  • AI 任务编号、发生时间、计费模式及相关错误信息（如适用）；
  • 问题说明及能够证明重复扣款、未到账或平台故障的截图；
  • 法律或支付渠道要求的其他必要核验信息。

请遮盖银行卡号、密码、验证码、完整 API Key、身份证件号码等非必要敏感信息。我们不会通过邮件索要您的密码或验证码。

6. 审核、返还与到账

  • 我们会在收到完整材料后的合理时间内核对账户、订单、任务、积分流水、交付记录和上游状态；复杂或涉及第三方的请求可能需要更长时间。
  • 积分返还将回到原站内账户；现金退款原则上退回原支付渠道。支付渠道不支持原路退回时，我们会依法与您确认可行方式。
  • 退款金额以实际支付且符合退款条件的部分为限。优惠、赠送权益和已经消费或交付的部分不折现。
  • 审核通过后的到账速度由银行、支付平台或其他渠道决定，本站无法控制其最终处理时间。
  • 退款成立后，与该交易对应而尚未使用的积分、商品或权益将被扣回、冻结或作废；已先行返还的积分不得重复申请现金补偿。

7. 拒付、争议与账户安全

未经沟通直接发起拒付、提供虚假材料或重复索赔，可能导致订单和账户被临时冻结以防止重复损失。该措施不影响您依法行使消费者权利。对处理结果有异议时，您可补充新证据再次沟通，或依法通过有管辖权的争议解决机构主张权利。

我们可能根据产品、支付渠道、上游服务或法律法规变化更新本政策，并在页面标注生效日期。已发生交易适用交易时公示的规则及法律强制性规定；更新不会减损您已经依法取得的权利。
