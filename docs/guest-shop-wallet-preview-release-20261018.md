## 运行内容

- 钱包支持 BSC (BEP20)、TON、Polygon、TRON (TRC20) 网络选择；网络和汇率快照参与重复请求识别。
- USDT 使用新鲜市场汇率预览和不可变报价，整数精度向上取整；报价变化需要再次确认。拒绝通道重复换汇或重复手续费。
- 入金币种、Memo 与精确实收金额参与回调核验，错误回调不覆盖原报价身份。保留支付宝在汇率服务不可用时的使用路径。
- 支付配置缓存与每次汇率响应分离，失败后恢复的汇率不再携带上一次错误。
- Verify 和本地预览保留 NOWPayments 原始 webhook 请求体供签名验证。
- 本地游客购买预览可显式使用同一个上游处理意图、下单、重试、取消和领取；本地取消 RPC 必须先通过上游买家及订单身份核验。
- 预览代理校验来源、回环地址和写操作授权，阻止跨站、路由覆盖、DNS 重绑定以及 webhook/worker 转发。
- 标准预览在启动时记录不可变源提交。`/healthz` 区分启动版本与磁盘当前版本，提供 `sourceMatchesStartup`、`restartRequired` 和 `productionEvidence: false`；所有响应带启动源 SHA，健康响应和静态资源不缓存。
