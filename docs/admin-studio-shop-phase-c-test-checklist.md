# Admin Studio 商城系统 Phase C 测试清单

这份清单用于 `Phase C` 的统一联调与 bug 回收。

本轮范围：

- `SC-C1` 内容经营页
- `SC-C2` 用户价值驾驶舱

## 1. 前置说明

- `Phase C` 本轮没有新增必须执行的 SQL migration
- 建议先确认 `Phase A`、`Phase B` 的 SQL 已执行完毕
- 联调时优先选 4 类样本：
  - 有明确带货支付的 Prompt
  - 有购买意图但未成交的 Prompt
  - 已出现退款或履约风险的带货样本
  - 已出现首单、复购、跨商品购买的用户样本

## 2. 自动化基线

先跑下面这组：

```bash
node -c admin-analytics.js
node -c js/admin-analytics-panel-loaders.js
node -c js/admin-analytics-workbench.js
node --test tests/frontend-supabase-runtime-config.test.js
node --test tests/admin-analytics-panel-support-bundle.test.js
node --test tests/admin-analytics-visual-panel-bundle.test.js
node --test tests/admin-analytics-product-bundles.test.js
```

预期：

- 全部通过
- 不出现 `contentOperatingCockpit` / `userValueCockpitStandalone` 相关断言失败

## 3. 内容经营页联调

1. 打开 `经营分析 -> 内容经营`
   预期：
   - 顶部先看到独立“内容经营页”
   - 页面不是直接落到旧的“内容带货详情”

2. 检查内容经营页主视图
   预期：
   - 有内容级经营判断
   - 有当前窗口摘要、指标卡、建议动作
   - 有“当前最值得盯的内容”列表

3. 点击内容经营页里的 `看带货详情`
   预期：
   - 能打开对应 Prompt 的内容带货详情
   - 详情里的 Prompt 标题与主视图当前聚焦一致

4. 点击内容经营页里的 `看主带货商品`
   预期：
   - 能跳到商品经营详情
   - 带着 Prompt / 信号上下文

5. 点击内容经营页里的 `看订单链`
   预期：
   - 能跳到商城订单
   - 订单列表保留内容经营来源上下文

6. 检查问题摘要卡
   预期：
   - `有意图未成交`、`退款样本`、`履约风险样本` 会按真实样本出现
   - 没问题时展示空态，不报错

7. 检查复查结论与历史回写
   预期：
   - 有回写时显示最新结论、最近动作、下次复查建议
   - 无回写时显示明确空态

## 4. 用户价值驾驶舱联调

1. 打开 `经营分析 -> 增长经营`
   预期：
   - 在增长页里能看到独立“用户价值驾驶舱”
   - 不是只出现在总览里的一个附属块

2. 检查用户价值主视图
   预期：
   - 有首单、复购、跨商品承接、高价值样本
   - 有当前价值层结论和建议动作
   - 有“最该复查的用户承接”

3. 点击高价值用户样本
   预期：
   - 能打开用户详情
   - 用户详情带着用户价值来源上下文

4. 点击 `首购商品去向` / `后续复购去向`
   预期：
   - 能跳到商品经营详情
   - 商品详情保留用户价值上下文

5. 检查退款风险用户场景
   预期：
   - 会出现支付问题 / 售后工单的建议动作
   - 跳转后能回到用户价值驾驶舱继续复查

6. 检查无成交或仅意图场景
   预期：
   - 文案会落到“意图待成交”或“价值层尚未形成”
   - 不会误报成复购已形成

## 5. 跨页联动与回写刷新

1. 从内容经营页跳到支付 / 售后 / 订单后完成处理
   预期：
   - 回到分析页后，内容经营页和内容带货详情的复查结论会刷新

2. 从用户价值驾驶舱跳到支付 / 售后 / 订单后完成处理
   预期：
   - 回到增长页后，用户价值驾驶舱会刷新

3. 从总览里的经营导航进入 `内容经营页` / `用户价值驾驶舱`
   预期：
   - 焦点会落到独立主视图，不会继续落到旧的附属块

## 6. 移动端与窄屏检查

1. 在窄屏下打开内容经营页
   预期：
   - Hero、优先级列表、问题摘要不挤坏
   - 按钮换行后仍可点击

2. 在窄屏下打开用户价值驾驶舱
   预期：
   - 用户价值卡片和样本区块能正常纵向排布
   - 不出现横向内容被截断不可读

## 7. 放行标准

满足下面条件再进入统一 bug 修复：

1. 自动化基线全绿
2. 内容经营页与内容带货详情的跳转稳定
3. 用户价值驾驶舱与商品 / 用户 / 支付 / 售后的跳转稳定
4. 回写后内容经营页、内容带货详情、用户价值驾驶舱都能刷新
5. 窄屏下内容经营页和用户价值驾驶舱无明显布局破坏
