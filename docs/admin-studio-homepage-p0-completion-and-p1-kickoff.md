# Admin Studio Homepage P0 完成说明 + P1 起步清单

更新时间：`2026-04-11`

## P0 完成说明

`Homepage P0` 已经完成并通过当前一轮联调验收，模块状态从“半成品工程”升级为“可发布、可回滚、可预览、可健康检查”的运营底座。

本轮 P0 已完成项：

- 统一了 Homepage contract，前台运行时、预取、显隐、后台编辑使用同一份站点化 schema
- 收掉了 `display_order / ticker / shop / guestbook` 等此前“可配但不一定生效”的伪配置
- 打通了 `draft / publish / rollback`
- 增加了 `CN / INTL + ZH / EN + Desktop / Mobile` 草稿预览摘要
- 增加了首页健康检查与发布前阻塞判断
- 收掉了首页精选 Prompt 的主要体验 bug，包括空白、只显示一张、滚动、排序反馈、按钮反馈等问题

P0 验收结论：

- 后台编辑不再直接覆盖线上
- 前台首页只消费发布版，后台草稿和线上状态已经解耦
- Homepage 已具备进入下一阶段编排能力建设的稳定基础

## P1 起步清单

P1 的目标不再是“继续补字段”，而是把 Homepage 做成一个真正可运营的首页增长编排台。

本轮 P1 起步范围：

1. Hero 结构化升级  
开放 Hero CTA、入口卡片和自定义背景图，首页首屏可以承接活动和业务导流。

2. Prompt 候选池闭环  
把 Gallery 里的候选 Prompt 拉进 Homepage 模块，支持一键加入首页精选，并回看候选表现。

3. Shop 首页位人工精选  
支持 `自动推荐 + 人工置顶` 混排，分类来源改为真实 `shop_categories`，首页位具备库存和上架状态感知。

4. Guestbook 首页位运营层  
支持精选留言、推荐理由和兜底卡片，避免社区内容异常时首页位直接塌陷。

5. Verify 模块业务化  
支持主卖点、支持模型、CTA、风险提示，并为首页 Verify 位补曝光/点击/转化归因。

6. Ticker 编排化  
支持 Prompt tags、商品分类、活动关键词、自定义条目等结构化内容源，前台渲染和后台开关一一对应。

7. Homepage Analytics 回流  
在 Homepage 里展示最近 7 天 / 30 天模块表现，支持候选池和首页位的效果对照。

8. 模板与定时  
支持从当前草稿保存模板、套用模板、创建定时发布和取消定时。

## P1 交付定义

P1 完成后，Homepage 模块应该具备：

- 可编排：Hero / Prompt / Shop / Verify / Guestbook / Ticker 都能按结构化数据编排
- 可观察：首页位能回看曝光、点击、转化和互动
- 可计划：模板和定时发布可承接活动期运营
- 可复用：候选池、模板、已上首页条目可以形成迭代闭环
