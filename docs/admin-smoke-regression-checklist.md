# 管理后台真人 Smoke 回归清单

这份清单用于这一轮“通知系统收缩 / 站内代办增强 / 客服工作台化 / 值班建议 / 交班报表 / 快捷回复模板配置化 / 个人提醒分类补全”的真人联调验收。

建议按“先桌面主链路，再权限边界，再移动端和长内容”的顺序执行。  
如果这次验收跑在正式环境，尽量只使用内部测试账号、测试会话和可回收样本数据。

## 1. 执行前准备

1. 准备 3 类账号：
   - 超级管理员账号
   - 普通管理员账号
   - 普通用户账号
2. 准备 1 组测试数据：
   - 至少 1 条客服测试会话
   - 至少 1 条带订单上下文的测试会话
   - 至少 1 条带支付或验证上下文的测试会话
   - 至少 1 条售后工单相关测试会话
   - 至少 1 条管理员安全提醒
   - 至少 1 条公告提醒
   - 至少 1 条 `admin_notice`
3. 浏览器准备：
   - Chrome 桌面端
   - Safari 或移动端真机任选 1 个
   - 执行前先强刷后台静态资源，避免吃旧缓存
4. 验收路径统一：
   - 后台入口：`/admin-studio.html`
   - 通知入口：页面右上角管理员铃铛
5. 记录方式：
   - 每条检查项标记 `通过 / 失败 / 阻塞`
   - 失败时记录页面路径、账号类型、时间、截图、复现步骤

## 2. 桌面端主链路

### 2.1 客服工作台

1. 用管理员账号登录后台。
2. 进入 `客服消息`。
3. 确认：
   - 左侧队列总览卡片正常显示
   - `交班摘要 / 适合切到 / 优先处理 / 协同安排` 三块值班建议正常显示
   - 队列列表能正常渲染，不空白、不闪烁
4. 点击 `切到建议视图`，确认：
   - 当前视图即时切换
   - 不出现整页跳动
   - 左侧列表会跟着过滤结果变化
5. 打开 1 条带订单上下文的会话，确认：
   - 顶部用户状态标签正常显示
   - `会话摘要` 面板正常显示
   - 快捷回复条正常显示
   - 点击 `订单说明` 后，正文会插入已插值文案，不应出现 `{{token}}`
6. 打开 1 条带验证或支付上下文的会话，确认：
   - 对应业务模板正常可见
   - 不适用的模板不会错误展示
7. 打开 1 条纯通用会话，确认：
   - 通用模板可见
   - 不会因为缺订单/支付数据导致面板报错

### 2.2 快捷回复模板配置

1. 进入 `站外告警 -> 监控规则 -> 客服消息告警 -> 快捷回复模板`。
2. 确认：
   - 模板卡片正常渲染
   - 业务类型、启用状态、使用场景、变量提示可见
   - 按钮文案、提示文案、回复正文输入框不溢出卡片
3. 对任意模板执行：
   - 修改按钮文案
   - 修改提示文案
   - 修改正文
   - 切换启用状态
4. 确认：
   - 启用开关切换时页面不跳动
   - 卡片状态即时更新
   - 预览文案同步更新
5. 点击变量标签插入变量，确认：
   - 会插入到当前聚焦输入框
   - 插入后文案格式正常
6. 新增 1 条模板并上下排序，确认：
   - 新模板不丢失
   - 排序后顺序稳定
   - 保存后刷新页面顺序仍一致
7. 输入非法变量或清空正文后保存，确认：
   - 保存被拦住
   - 错误字段高亮
   - 卡片底部有明确错误摘要
8. 修正错误后再次保存，确认：
   - 错误态自动清除
   - 保存成功提示正常
9. 回到 `客服消息`，确认刚才改动已生效：
   - 启停结果正确
   - 模板顺序正确
   - 模板文案正确

### 2.3 管理员铃铛 / 个人提醒

1. 打开右上角管理员铃铛。
2. 确认：
   - 分类筛选存在：`全部提醒 / 待办转交 / 安全提醒 / 公告协同 / 管理通知`
   - 状态筛选存在：`全部 / 未读 / 已读`
3. 逐个切换分类，确认：
   - 列表只显示命中分类的提醒
   - 空态文案会跟随分类变化
4. 切到 `未读`，确认：
   - 只保留未读通知
   - 未读徽标数量同步变化
5. 对任意通知执行 `置顶`，确认：
   - 该条会立刻排到前面
   - 关闭抽屉再打开后，本地记忆仍在
6. 点击 `全部已读`，确认：
   - 列表未读态清空
   - 红点或数字徽标同步清空
7. 关闭抽屉后重新打开，确认：
   - 分类筛选和 `全部 / 未读 / 已读` 状态会记忆上次选择

### 2.4 交班报表

1. 进入 `站外告警` 对应的交班报表区域。
2. 依次切换：
   - `全览`
   - `交接优先`
   - `闭环复盘`
   - `我的接班`
3. 每切换一次都确认：
   - headline 和指标卡同步变化
   - 模块列表同步变化
   - 人员统计同步变化
4. 点击 `复制交班摘要`，确认：
   - 复制内容与当前视角一致
   - 不是旧视角内容
5. 点击 `导出交班 CSV`，确认：
   - 能正常下载
   - 文件不为空
   - 导出内容与当前视角一致

## 3. 权限边界回归

### 3.1 普通管理员

1. 用普通管理员账号登录后台。
2. 确认：
   - 可以进入客服工作台
   - 可以查看交班报表
   - 可以使用通知中心筛选
3. 如果产品策略要求普通管理员不能修改某些后台配置，再确认：
   - 快捷回复模板配置入口是否按预期显示或禁用
   - 不应出现越权保存成功

### 3.2 普通用户

1. 退出后台账号，登录普通用户账号。
2. 尝试直接访问 `/admin-studio.html`。
3. 确认：
   - 前端会拦截后台访问
   - 后端接口不会返回管理员数据
   - 即使知道后台路径，也不能进入管理内容

## 4. 移动端与长内容回归

### 4.1 客服工作台

1. 在窄屏设备或 DevTools `390 x 844` 视口打开后台。
2. 进入 `客服消息`，确认：
   - 队列总览卡片不横向溢出
   - 值班建议块不横向溢出
   - 会话列表不横向溢出
   - 会话摘要卡片不横向溢出
   - 快捷回复条可以换行，不会撑破容器
3. 打开带长订单名的会话，确认：
   - 模板文案会换行
   - 输入框与消息区布局稳定

### 4.2 通知中心

1. 在窄屏设备或 DevTools `390 x 844` 视口打开通知抽屉。
2. 确认：
   - 抽屉本身不横向溢出
   - 分类筛选条不横向溢出
   - 长标题通知会自然换行
   - 长正文通知会自然换行
   - 置顶、已读、关闭按钮仍可点击

## 5. 长数据与异常值回归

1. 至少人工验证 1 组长数据：
   - 长订单名
   - 长邮箱
   - 长公告标题
   - 长管理通知正文
2. 确认：
   - 不截断到不可读
   - 不把卡片撑破
   - 不产生横向滚动条
3. 至少人工验证 1 组缺失数据：
   - 无订单上下文
   - 无支付上下文
   - 无验证上下文
   - 无工单上下文
4. 确认：
   - 页面不会报错
   - 快捷回复会正确降级到通用模板
   - 通知不会因为缺字段而无法显示

## 6. 回归结果记录模板

每条失败项建议至少记录：

- 模块
- 页面路径
- 账号类型
- 设备或视口
- 复现步骤
- 实际结果
- 预期结果
- 截图
- 是否阻塞上线

## 7. 本轮最低放行标准

满足以下条件，才建议把这轮收尾项视为“真人回归通过”：

1. 客服工作台主链路通过
2. 快捷回复模板配置到工作台回填通过
3. 管理员铃铛筛选、已读/未读、置顶通过
4. 交班报表视角切换、复制、导出通过
5. 普通用户后台拦截通过
6. 移动端窄屏无明显横向溢出
7. 长文案和缺失数据场景无阻塞问题
