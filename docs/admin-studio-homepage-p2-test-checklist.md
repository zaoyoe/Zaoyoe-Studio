# Admin Studio 首页模块 P2 测试清单

这份清单用于统一执行 `Homepage P2` 的联调、回归和 bug 回收。

适用范围：

- `P2-H1` 轻量实验能力
- `P2-H2` 推荐辅助与运营建议
- `P2-H3` 自动巡检与运营告警
- `P2-H4` 主题包与场景化编排

建议按“先跑自动化基线 -> 再跑后台配置链路 -> 再跑前台验证链路 -> 最后集中收 bug”的顺序推进。

- 缺陷登记模板：[docs/admin-studio-homepage-p2-defect-template.md](/Volumes/chao/AI/xianyu_profit_calculator/docs/admin-studio-homepage-p2-defect-template.md)

## 1. 执行前准备

1. 准备 1 个管理员账号：
   - 可以访问 `/admin-studio.html`
   - 可以进入 `主页内容`
   - 可以执行 `保存修改 / 发布当前站点 / 回滚上一版`
2. 准备 2 个前台验证视角：
   - 正常浏览器窗口
   - 隐身窗口或另一浏览器，用于验证实验分流
3. 准备 2 个站点环境：
   - `CN 站`
   - `国际站`
4. 准备 5 类测试样本：
   - 至少 8 张可用于首页精选的 Prompt 卡片
   - 至少 4 个可售商品，且当前站点价格已配置
   - 至少 4 条可用于精选的留言板内容
   - 至少 1 套 Hero 已保存草稿
   - 至少 1 套可用于主题包覆盖的现有草稿
5. 浏览器建议：
   - Chrome 桌面端
   - 窄屏视口 `390 x 844`
6. 记录规则：
   - 每条检查项标记 `通过 / 失败 / 阻塞 / 不适用`
   - 失败时记录 `站点 / 页面路径 / 操作步骤 / 实际结果 / 预期结果 / 截图`

## 4. 真人主链路回归

### 4.1 `P2-H1` 轻量实验能力

#### `HP-P2-EX-01` Hero 标题实验创建

1. 进入 `Admin Studio -> 主页内容 -> P2 轻量实验`。
2. 选择 `Hero 标题` 槽位。
3. 输入实验名、流量比例、变体文案。
4. 点击保存。
5. 确认：
   - 保存成功有明确反馈
   - 页面刷新后实验仍存在
   - Control 预览显示当前草稿文案
   - Variant 预览显示新文案

#### `HP-P2-EX-02` Hero 副标题实验分流

1. 为 `Hero 副标题` 再创建 1 个实验。
2. 发布当前站点。
3. 用正常窗口和隐身窗口分别打开首页。
4. 刷新 3-5 次。
5. 确认：
   - 不同会话有机会命中不同版本
   - 同一会话刷新时分组基本稳定
   - 页面不闪烁、不报错

#### `HP-P2-EX-03` Verify CTA 文案实验

1. 选择 `Verify CTA` 槽位。
2. 设置一条明显不同的 CTA 文案。
3. 保存并发布。
4. 打开首页验证模块。
5. 确认：
   - 当前站点主语言的 CTA 文案被替换
   - 不会错误影响另一站点语言

#### `HP-P2-EX-04` Prompt 精选列表实验

1. 为 `Prompt 精选` 建立列表实验。
2. 用不同于当前草稿的一组精选卡片作为 Variant。
3. 保存并发布。
4. 前台刷新首页。
5. 确认：
   - 首页提示词精选整体换为 Variant 列表
   - 显示为网格多卡，不会退化成单张大图
   - 卡片上不再出现标签回归

#### `HP-P2-EX-05` 商城精选列表实验

1. 为 `商城精选` 建立列表实验。
2. 保存并发布。
3. 前台滚动到商城区。
4. 确认：
   - 商品滚动区正常出现
   - 精选商品变化与 Variant 一致
   - 没有因空价格或空候选池导致整段消失

#### `HP-P2-EX-06` 留言板精选列表实验

1. 为 `留言板精选` 建立实验。
2. 保存并发布。
3. 前台打开首页留言板区。
4. 确认：
   - 展示内容与 Variant 一致
   - 不会串到 Prompt 或 Shop 数据

#### `HP-P2-EX-07` 实验数据回流

1. 在前台分别点击 Hero、Prompt、Shop、Verify、Guestbook 相关入口。
2. 回到后台刷新 `P2 轻量实验` 卡片。
3. 确认：
   - 曝光数有变化
   - 点击数有变化
   - CTR 计算正常，不出现 `NaN` 或空白异常

#### `HP-P2-EX-08` 一键应用胜出版本

1. 找到已有结果的实验。
2. 点击“应用胜出版本”。
3. 返回对应 section 草稿区域查看。
4. 确认：
   - 当前草稿已替换成胜出版本
   - 实验条目被收口或移除
   - 前台发布后能直接看到胜出内容

#### `HP-P2-EX-09` 删除实验

1. 对任意未收口实验执行删除。
2. 刷新页面。
3. 确认：
   - 实验记录消失
   - 草稿不会残留脏数据
   - 前台不再命中该实验

#### `HP-P2-EX-10` 站点隔离

1. 在 `CN 站` 创建一个 Hero 文案实验。
2. 切到 `国际站`。
3. 确认：
   - 国际站看不到 CN 站实验
   - 国际站前台文案不受 CN 站实验影响

### 4.2 `P2-H2` 推荐辅助与运营建议

#### `HP-P2-RC-01` 推荐卡片渲染

1. 进入 `P2 推荐辅助` 卡片。
2. 确认：
   - 卡片能正常展示
   - 有信号时显示信号说明
   - 无信号时显示空态，不报错

#### `HP-P2-RC-02` Prompt 推荐应用

1. 对 Prompt 推荐点击“应用建议”。
2. 返回 `首页精选 Prompt` 区域。
3. 确认：
   - 草稿精选列表被更新
   - 顺序与推荐结果一致
   - 保存后刷新仍保留

#### `HP-P2-RC-03` 商城推荐应用

1. 对 Shop 推荐点击“应用建议”。
2. 返回 `人工精选商品` 区域。
3. 确认：
   - 商品已加入人工精选或补强列表
   - 候选池不会被错误清空

#### `HP-P2-RC-04` 留言板推荐应用

1. 对 Guestbook 推荐点击“应用建议”。
2. 返回留言板精选区域。
3. 确认：
   - 精选留言已替换
   - 不会出现重复条目

#### `HP-P2-RC-05` 推荐应用后发布

1. 对任意推荐执行应用。
2. 保存草稿并发布。
3. 前台刷新。
4. 确认：
   - 推荐结果已真实生效
   - 不是只在后台预览中可见

#### `HP-P2-RC-06` 站点隔离

1. 在 `CN 站` 应用一条推荐。
2. 切换到 `国际站`。
3. 确认：
   - 国际站草稿未被串写
   - 推荐内容按站点单独计算

### 4.3 `P2-H3` 自动巡检与运营告警

#### `HP-P2-AL-01` 告警卡片渲染

1. 打开 `P2 巡检与告警` 卡片。
2. 确认：
   - 告警列表正常展示
   - 严重级别和说明文字可读
   - 无告警时显示空态

#### `HP-P2-AL-02` 关键模块误隐藏告警

1. 暂时关闭一个关键模块，例如 `Verify` 或 `Shop`。
2. 保存草稿并刷新后台。
3. 确认：
   - 出现误隐藏类告警
   - 恢复该模块后告警消失

#### `HP-P2-AL-03` 健康检查告警汇总

1. 人为制造一项不完整配置，例如去掉关键链接或精选数据。
2. 刷新后台。
3. 确认：
   - 健康检查中的错误或警告会映射到告警卡片
   - 文案不是纯技术报错

#### `HP-P2-AL-04` 实验收口提醒

1. 保留一个已有明显数据差异的实验。
2. 进入后台刷新告警区域。
3. 确认：
   - 能看到实验胜出或待收口提醒

#### `HP-P2-AL-05` 日报复制

1. 点击“复制日报”。
2. 粘贴到记事本或输入框。
3. 确认：
   - 内容非空
   - 包含站点、时间、核心风险、建议摘要

#### `HP-P2-AL-06` 周报复制

1. 点击“复制周报”。
2. 粘贴到记事本或输入框。
3. 确认：
   - 内容非空
   - 不是简单重复日报
   - 包含近一周概览或趋势描述

#### `HP-P2-AL-07` 站点隔离

1. 切换站点重新查看告警与报告。
2. 确认：
   - 两个站点的告警不会串数据
   - 文案和指标按当前站点变化

### 4.4 `P2-H4` 主题包与场景化编排

#### `HP-P2-TP-01` 主题包列表渲染

1. 进入 `P2 主题包` 卡片。
2. 确认：
   - 能看到内置主题包列表
   - 每个主题包有名称、说明和覆盖 section 预览

#### `HP-P2-TP-02` 全量套用主题包

1. 选择一个主题包。
2. 勾选全部模块。
3. 点击应用。
4. 确认：
   - Hero、Prompt、Shop、Verify、Guestbook、Ticker 同步更新到草稿
   - 页面刷新后草稿仍保留

#### `HP-P2-TP-03` 局部套用主题包

1. 选择另一个主题包。
2. 仅勾选 `Hero + Verify`。
3. 点击应用。
4. 确认：
   - 只有勾选模块变化
   - 其他模块维持原草稿内容

#### `HP-P2-TP-04` 国际站主题包

1. 切到 `国际站`。
2. 应用国际化或新品发布主题包。
3. 确认：
   - 文案语言合理
   - 不会混入中文站内容

#### `HP-P2-TP-05` 套用后发布

1. 套用任意主题包。
2. 保存并发布。
3. 打开前台首页。
4. 确认：
   - 前台内容与后台草稿一致
   - 没有局部 section 丢失

#### `HP-P2-TP-06` 与模板能力兼容

1. 套用主题包后再保存为模板。
2. 再从模板重新应用一次。
3. 确认：
   - 模板保存成功
   - 模板重放结果与原主题包草稿一致

## 5. 发布链路与回归补充

### `HP-P2-RG-01` 草稿不直出

1. 在后台修改实验、推荐或主题包内容，但不发布。
2. 前台刷新。
3. 确认：
   - 前台仍显示上一已发布版本
   - 草稿不会直接漏到线上

### `HP-P2-RG-02` 发布后生效

1. 发布当前站点。
2. 前台首页、`prompts.html`、`shop.html`、`verify.html`、`guestbook.html` 分别刷新。
3. 确认：
   - 内容同步更新
   - 没有旧缓存导致的前后台不一致

### `HP-P2-RG-03` 回滚后恢复

1. 在发布新版本后立即执行回滚。
2. 前台刷新。
3. 确认：
   - 页面恢复到上一已发布版本
   - 不残留新版本局部内容

### `HP-P2-RG-04` 旧功能回归

至少回归下面已有功能不被 P2 影响：

1. Hero 入口编排可滚动
2. Prompt 精选网格展示正常
3. Prompt 卡片不显示标签
4. Shop 自动聚合可出商品滚动
5. 发布按钮点击反馈正常
6. 首页精选上移/下移反馈正常

## 6. 兼容性与异常值回归

至少人工验证下面 8 组边界场景：

1. 空数据站点打开 P2 卡片，显示空态但不报错
2. 低流量实验显示 `0` 曝光或 `0` 点击时，CTR 不异常
3. 候选池为空时，推荐与主题包仍可正常渲染
4. 商城商品缺少当前站点价格时，不会把整个首页商城区打挂
5. 留言板精选数量不足时，实验和推荐仍能保存
6. 移动端窄屏下，P2 卡片内容可滚动、按钮不重叠
7. 多次切换站点后，后台不串写对方站点草稿
8. 浏览器硬刷新后仍能加载最新脚本版本

## 7. 本轮最低放行标准

满足下面条件，才建议把 `Homepage P2` 视为真人回归通过：

1. 五类实验位都能创建、展示、删除，并能回流基础数据。
2. 至少一条推荐建议可以成功写回草稿并发布生效。
3. 告警、日报、周报都能正常展示与复制。
4. 至少一套主题包可全量套用，至少一套主题包可局部套用。
5. 草稿 / 发布 / 回滚主链路无回归。
6. `CN 站` 与 `国际站` 数据严格隔离。
7. 自动化基线通过，且真人回归无阻塞上线的高优问题。
