# Admin Studio 首页模块 P2 缺陷登记模板

这份模板用于统一登记 `Homepage P2` 回归阶段发现的问题，方便后续集中修复、复测和收口。

建议每条 bug 单独成条，不要把多个问题混在同一条里。

## 1. 缺陷标题格式

建议统一使用下面格式：

`[Homepage P2][模块][站点] 一句话描述问题`

示例：

- `[Homepage P2][轻量实验][CN] Hero 标题实验发布后前台始终命中 control`
- `[Homepage P2][推荐辅助][INTL] 商城推荐应用后候选池被清空`
- `[Homepage P2][主题包][CN] 局部套用 Hero+Verify 时 Shop 内容被误覆盖`

## 3. 建议标签

按问题归类时，建议补充下面标签，方便统一拉清单：

- `HomepageP2-Experiment`
- `HomepageP2-Recommendation`
- `HomepageP2-Alerts`
- `HomepageP2-ThemePack`
- `HomepageP2-Publish`
- `HomepageP2-CN`
- `HomepageP2-INTL`
- `HomepageP2-Regression`

## 4. 优先级建议

建议统一按下面口径标记：

- `P0`
  - 阻塞发布
  - 草稿 / 发布 / 回滚主链路失败
  - 首页白屏、核心 section 整段消失
  - 站点数据串写
- `P1`
  - 关键功能不可用
  - 实验、推荐、告警、主题包有一项主能力失效
  - 前台展示严重错误但有临时绕过方式
- `P2`
  - 逻辑基本可用，但交互、反馈、局部结果不正确
  - 单个边界场景处理不稳
- `P3`
  - 文案、样式、提示语、空态、轻微体验问题

## 5. 判定是否阻塞上线

满足任一条件，建议标记为“阻塞上线”：

1. 发布后首页核心模块异常或缺失。
2. 回滚失败，无法恢复到上一发布版本。
3. 实验配置导致线上内容错乱，且不能快速删除恢复。
4. 主题包或推荐应用导致跨站点串写。
5. 后台保存成功但前台完全不生效，且无法通过重新发布恢复。
